# LSB-Image-Steganography-Project-

🚀 **Project Showcase: Steganography in C | Hiding Secret Information Inside an Image**

I’m happy to share one of my hands-on projects, **Steganography**, which helped me explore how secret information can be hidden inside an ordinary image and retrieved later using C programming.

🔐 **What is Steganography?**

Steganography is the technique of hiding secret information within an ordinary file, such as an image, audio file, or video, so that the presence of the hidden information is not easily noticeable.

Unlike encryption, which transforms a message into an unreadable form, steganography focuses on concealing the existence of the message itself.

💻 **Project Overview**

In this project, I worked on hiding secret text information inside a BMP image and extracting the original information from the encoded image.

The project is divided into two main modules:

🔹 **1. Encoding**
- Read the source image and secret file.
- Validate the input files and required file formats.
- Embed the secret file information into the image using bit-level operations.
- Generate a stego image containing the hidden data.

🔹 **2. Decoding**
- Read the encoded image.
- Extract the hidden information from the image.
- Recover the original secret file and its contents.
